# Ontology Based bi-lingual Lexicon for Semantic search in Roman Urdu
Bilingual Ontology for Roman Urdu to English with Semantic search algoithm and roman metaphone pseudo codes
**Usage**
**BiOnt.zip**
Unzip this file and explore in protege or read through APIs.
**Rumeta**
This is java class that can be run directly in any java environment. It encodes any given string to respective phonetic code.
