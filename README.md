# Ontology-Driven Single-Word Roman Urdu Cross-Lingual Query Expansion For Multilingual Information Retrieval
***Usage***<br> 
### Repository Contents and Reproducibility

This repository provides the source code, ontology, experimental artifacts, and supporting documentation for the proposed Roman Urdu information retrieval framework. The main implementation comprises three standalone Java classes: **RuMetA.java** (Roman Urdu phonetic encoding), **RASOM.java** (Rule-based Approximate String-to-Ontology Matching), and **BRUSE.java** (ontology-driven multilingual semantic query expansion), together with the **BiOnt.owl** bilingual ontology. The repository also contains three evaluation directories: **RASOM Evaluation**, **BORUE Evaluation**, and **BRUSE Evaluation**. Each directory includes a detailed reproducibility document describing the experimental methodology, execution instructions, input/output files, and associated artifacts; a **Code** folder containing the relevant implementation scripts; and a **Results** folder containing experimental outputs in the form of Excel workbooks, tables, or figures, wherever applicable. These resources are provided to facilitate independent verification, replication, and further investigation of the proposed framework.
